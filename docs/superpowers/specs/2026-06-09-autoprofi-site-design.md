**Дата:** 2026-06-09  
**Статус:** На ревью

---

## 1. Контекст и цель

Коммерческий сайт по продаже и установке фаркопов. Целевая аудитория — владельцы автомобилей, которые знают что ищут (конкретная марка/модель) или выбирают впервые. Главная задача сайта — **конвертировать поиск в заявку**: подобрал по авто → выбрал товар → позвонил/оставил заявку.

Вдохновение по структуре и визуальному стилю: [TAG Towbars AU](https://www.tagtowbars.com.au/).

## 3. Дизайн-система

### Цвета

```css
--bg-primary:    #000000;   /* основной фон */
--bg-secondary:  #111111;   /* карточки, секции */
--bg-tertiary:   #1a1a1a;   /* hover-состояния, borders */
--accent:        #F59E0B;   /* янтарный — CTA, ссылки, иконки */
--accent-hover:  #D97706;   /* hover на акценте */
--text-primary:  #FFFFFF;
--text-muted:    #9CA3AF;   /* gray-400 */
--text-dim:      #4B5563;   /* gray-600 — второстепенное */
--border:        #1F2937;   /* gray-800 */
```

### Типографика

| Роль | Шрифт | Вес | Размер |
|------|-------|-----|--------|
| Display / Hero | `Bebas Neue` (Google) | 400 | 48–72px |
| Заголовки H2–H3 | `Inter` | 700–900 | 24–36px |
| Body / UI | `Inter` | 400–500 | 14–16px |
| Лейблы / капс | `Inter` | 600 | 11–12px, tracking wide |

> Bebas Neue — промышленный, агрессивный display-шрифт. Идеален для Hero и названий категорий. Inter — системный, читаемый для всего остального.

### Эффекты и анимации

- Hover на карточках: `border-color` → `--accent` + лёгкий `box-shadow` (`0 0 0 1px #F59E0B33`), `duration-200`
- Hover на кнопках: `bg-accent-hover`, `duration-150`
- Переходы страниц: стандартный Next.js, без кастомных loader'ов пока
- `prefers-reduced-motion`: все анимации через `transition-*`, уважают системные настройки
- Нет параллакса, нет тяжёлых анимаций — производительность важнее

## 5. Главная страница — детальная структура

### Блок 01 · Topbar
Узкая полоса над хедером. Фон `--bg-secondary`. Содержит:
- Телефон (кликабельный `tel:`)
- Часы работы
- Промо-текст (например, «Бесплатный выезд на замер»)

### Блок 02 · Header / Nav
Sticky. Фон `#000` с `backdrop-blur` при скролле. Содержит:
- Логотип AUTOPROFI (SVG, акцентный цвет)
- Навигация: Каталог ▾, Подбор по авто, Услуги, О нас, FAQ, Контакты
- Иконка поиска (справа)
- На мобильном: бургер-меню

### Блок 03 · Селектор авто *(ключевой блок)*
**Решение:** отдельная полоса под хедером, не наложена на Hero.  
**Обоснование:** максимальная видимость инструмента, гарантированный контраст, нет конкуренции с фоновым изображением.

Поля (каскадные — каждое следующее активируется после выбора предыдущего):
1. Марка (обязательное)
2. Модель (активируется после марки)
3. Год (активируется после модели) → год резолвит поколение внутри `getGenerationByMakeModelYear()`

После выбора года `CarSelector` вызывает `getGenerationByMakeModelYear(make, model, year)` → получает `carSlug` поколения → кнопка «Найти фаркоп» редиректит на `/cars/[carSlug]`.

Если для выбранного года есть несколько кузовов — показать шаг 4 «Кузов» (опциональный, появляется динамически).

Фон блока: `--bg-secondary`, чёткая граница снизу `--border`.

### Блок 04 · Hero Banner
Большое фоновое изображение (авто сзади с установленным фаркопом). Тёмный оверлей для читаемости текста.

Левая часть:
- Display-заголовок (Bebas Neue): «ФАРКОПЫ ПОД ЛЮБОЕ АВТО»
- Подзаголовок: «Продажа · Установка · Гарантия · Документы»
- Две кнопки: [СМОТРЕТЬ КАТАЛОГ] (акцент, primary) + [Записаться на установку] (outline)

Правая часть: список преимуществ с галочками (как у TAG — bullet list).

### Блок 05 · Преимущества
5 иконок в ряд. Фон `--bg-secondary`. Содержит:
1. Профустановка мастерами
2. Документы / совместимость с ТО
3. Гарантия 2 года
4. 500+ авто в базе
5. Выезд мастера к вам

### Блок 06 · Каталог по категориям
**Таксономия:** только категории верхнего уровня. Типы крюка (фланцевый/съёмный/вертикальный) — это фильтры внутри `/catalog`, не плитки на главной.

3 основные плитки + 1 вспомогательная:
1. **Фаркопы** → `/catalog`
2. **Электрика** → `/catalog?cat=electrics`
3. **Аксессуары** → `/catalog?cat=accessories`
4. **Установка** → `/services` (приглушённая — это не товар)

Каждая плитка: фото товара + название + стрелка.

### Блок 07 · Популярные авто *(SEO)*
Заголовок: «Часто ищут фаркоп для:»  
Чипы показывают **название модели** (Toyota RAV4), но ссылаются на `/cars?make=toyota&model=rav4` — pre-fill CarSelector на странице `/cars`. Пользователь выбирает год → попадает на нужное поколение.

**Почему не прямая ссылка на поколение:** у одной модели может быть 2–3 актуальных поколения, мы не знаем заранее какой год у пользователя. Ссылка на pre-filled selector — честнее и удобнее.

Список из `getPopularCars()` (~10 позиций, hardcoded в data.ts).  
Примерный список: Toyota RAV4, Kia Sportage, Hyundai Tucson, VW Tiguan, Skoda Kodiaq, Nissan X-Trail, Lada Vesta SW Cross, Renault Duster, Ford Explorer, Mitsubishi Outlander.

### Блок 08 · CTA — Запись на установку
Тёмный баннер (полная ширина). Текст слева + кнопка справа.  
Текст: «Привезём и установим за 1–2 часа. Оформляем документы.»  
Кнопка: [Записаться →] (акцент)

### Блок 09 · Блог / Полезное
3 карточки последних статей из `/blog`. Заголовок + дата + превью-текст. Ссылка «Все статьи →».

### Блок 10 · Footer
4 колонки:
- Логотип + адрес + телефон + email + ИНН
- Каталог: Фаркопы, Электрика, Аксессуары
- Компания: Услуги, О нас, FAQ, Блог
- Помощь: Доставка, Гарантия, Контакты, VK / Telegram

Нижняя строка: копирайт + ссылки на политику конфиденциальности.

## 7. Слой данных

### Формат carSlug *(решение принято 2026-06-09)*

**Уровень: поколение**, не модель. Фаркоп подходит на поколение, RAV4 2015 ≠ RAV4 2023.  
Формат: `[make]-[model]-[generation]-[yearStart]`  
Примеры: `toyota-rav4-5-2019`, `audi-a4-b9-2015`, `kia-sportage-4-2021`

```ts
// Структура записи в cars.json
{
  "slug": "toyota-rav4-5-2019",      // уникальный ключ — поколение
  "make": "Toyota",
  "makeSlug": "toyota",
  "model": "RAV4",
  "modelSlug": "rav4",
  "generation": 5,
  "yearStart": 2019,
  "yearEnd": null,                    // null = по н.в.
  "bodyTypes": ["SUV"],
  "displayName": "Toyota RAV4 (V поколение, 2019–н.в.)"
}
```

**SEO-эффект:** пользователь ищет «фаркоп рав4 2020» → попадает на `/cars/toyota-rav4-5-2019` напрямую.

### Структура URL категорий (явно)
- `/catalog/[brand]` — **маршрут** (SSG), отдельная страница под бренд фаркопа (Bosal, Westfalia и т.д.) — для SEO
- `/catalog?cat=electrics` — **query param**, фильтрация по категории товара внутри общего каталога — не отдельный маршрут

### Функции data.ts

```ts
// lib/data.ts — единственная точка доступа

// --- Авто (уровень: поколение) ---
getCars()                                        // все поколения всех авто
getCarBySlug(slug: string)                       // поколение по slug
getMakes()                                       // список марок
getModelsByMake(make: string)                    // модели по марке
getYearsByMakeModel(make: string, model: string) // все годы выпуска модели (из всех поколений)
getGenerationByMakeModelYear(                    // резолвинг поколения по году → carSlug
  make: string, model: string, year: number
): Car | undefined
getPopularCars(limit?: number)                   // hardcoded топ для SEO-блока главной

// --- Товары ---
getProducts()                                    // все товары
getProductById(id: string)                       // товар по id
getProductsForCar(carSlug: string)               // товары под поколение авто
getProductsByCategory(cat: 'towbars' | 'electrics' | 'accessories')
getProductsByBrand(brand: string)                // для /catalog/[brand]

// --- Блог ---
getBlogPosts()
getBlogPostBySlug(slug: string)
getLatestBlogPosts(limit?: number)
```

## 8. SEO-слой

- `generateStaticParams` на `/cars/[carSlug]`, `/catalog/[brand]`, `/product/[id]`, `/blog/[slug]`
- `generateMetadata` на каждой странице: уникальные `title` и `description` из данных
- `app/sitemap.ts` — генерирует все статические URL
- `app/robots.ts` — разрешает всё, блокирует `/api/`
- JSON-LD: `LocalBusiness` на главной и контактах, `Product` на карточках товаров
- Семантический HTML: `<nav>`, `<main>`, `<article>`, `<section>` с правильными heading-иерархиями
- Все изображения: `alt` обязателен, `next/image` с `priority` на LCP-изображениях

- Онлайн-оплата

- Корзина

5. **SEO-слой** — sitemap, robots, metadata, JSON-LD
6. **Формы** — заявка на установку, обратный звонок (заглушка)
